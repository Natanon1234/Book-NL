\section{Text, lists, and margin notes}
\labsec{cookbook-text}
Use \texttt{\string\section[short title]\{full title\}} when a long heading needs a shorter table-of-contents entry. Place project labels immediately after the item being labeled, such as \texttt{\string\labsec\{unique-key\}} after a section heading.

\subsection{Lists}
\begin{itemize}
  \item Use an unordered list for related concepts.
  \item Nest items when the hierarchy is meaningful.
  \begin{itemize}
    \item Nested bullets use the project’s smaller bullet style.
  \end{itemize}
\end{itemize}
\begin{enumerate}
  \item Use numbered steps when order matters.
  \item Continue with the next action or consequence.
\end{enumerate}
\begin{description}
  \item[Term] Explain a defined term or a short item-label pair.
  \item[Second term] Keep descriptions concise and parallel.
\end{description}

Use \texttt{\string\marginnote} for an ordinary margin note. Use \texttt{\string\sidenote} for a numbered note. For example, \sidenote{A short note in the outer margin.} Keep longer explanations in the main text or a box.

\subsection{Project typography helpers}
The preamble defines small typography helpers: \invitro experiments, \invivo observations, \cis and \trans configurations, \etal citations, \denovo mutations, \adhoc choices, \eg examples, \ie clarifications, and \etcetera. Commands such as \Command{section}, \Package{booktabs}, and \Path{assets/} print technical names consistently.

\section{Equations, definitions, and theorems}
\labsec{cookbook-math}
For a numbered equation, place the project label inside the environment:
\begin{equation}
  C = \frac{n}{V}
  \labeq{concentration-example}
\end{equation}
The relationship is shown in \refeq{concentration-example}. Use \texttt{wideequation} when more width is needed:
\begin{wideequation}
  \Delta G = \Delta G^{\circ} + RT\ln Q
\end{wideequation}
\begin{definition}
  Concentration is the amount of a substance per unit volume.
  \labdef{concentration-example}
\end{definition}
\begin{theorem}
  In this example, doubling amount while holding volume fixed doubles concentration.
  \labthm{concentration-example}
\end{theorem}
\begin{remark}
  Available theorem-like environments include theorem, proposition, lemma, corollary, definition, remark, example, and exercise.
\end{remark}

\section{Code, citations, and references}
\labsec{cookbook-references}
Use \texttt{lstlisting} for short code samples:
\begin{lstlisting}[language=Python,caption={A short code listing.},label={lst:example}]
concentration = amount / volume
print(concentration)
\end{lstlisting}
The bibliography is stored in \texttt{main.bib} and processed with Biber.

Use \texttt{\string\textcite} for prose citations and \texttt{\string\parencite} for parenthetical citations. For example, \textcite{Costanzo2014BRS} discusses physiology; see also \parencite[chap.~1]{Costanzo2014BRS}. The custom \texttt{\string\sidecite} adds a citation in the margin: \sidecite{Costanzo2014BRS}.

Project reference helpers pair each label type with its matching reference command. For example, use \texttt{\string\labsec} with \texttt{\string\refsec}, \texttt{\string\labfig} with \texttt{\string\reffig}, and \texttt{\string\labtab} with \texttt{\string\reftab}. See \refsec{cookbook-boxes}, \reftab{example_planning_table}, and \reffig{tikz-flow}. The complete command list is in \texttt{template/kaorefs.sty}.

\section{TikZ shapes and colors}
\labsec{cookbook-tikz}
TikZ is loaded by the project template. Define nodes with shape, fill, and line options, then connect them with paths:
\begin{center}
\begin{tikzpicture}[>=stealth]
  \node[draw,circle,fill=ForestGreen!20,minimum size=1.2cm] (one) at (0,0) {1};
  \node[draw,rounded corners,fill=RoyalBlue!15,minimum width=2.2cm,minimum height=1cm] (two) at (3,0) {Process};
  \draw[->,very thick,Goldenrod] (one) -- (two);
\end{tikzpicture}
\end{center}
Available colors include names from \texttt{xcolor} with the \texttt{dvipsnames} option. Mix a color with white for a pale fill. Reusable TikZ styles can be declared locally or globally in the preamble.
