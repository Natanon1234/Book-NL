%  FIGURE AND TABLE TEMPLATES  (kaobook, NL virology notes)
% =====================================================================
%
%  RULES
%   1. Every figure and table is a float (figure / table, or the kaobook
%      variants below). Never use  center + \captionof.
%   2. Order inside the float:
%        figure:  \centering -> content -> \caption -> \labfig
%        table:   \centering -> \caption -> \labtab -> content
%      The label goes IMMEDIATELY after \caption. A label placed before
%      the caption points at the section number instead of the float.
%   3. Always give a short caption in [ ]. It is what appears in the list
%      of figures / tables. Keep \cite and \footnote out of the short caption.
%   4. Labels are the bare name with no prefix: \labfig{c2-capsid-shapes}.
%      (\labfig / \labtab add fig: / tab: themselves.)
%      Naming convention: <chapter>-<kebab-case-name>, e.g. c2-dissemination.
%   5. Refer to every float in the text with \reffig{name} / \reftab{name}.
%      They print "Figure N" / "Table N", so never type "Figure~\ref{...}".
%      Place the float right after the paragraph that first refers to it.
%   6. Non-float references stay as they are:
%        Section~\ref{...}   Chapter~\ref{...}   Box~\ref{box:...}
%   7. Credit the source in the caption ("Reproduced from ...",
%      "Adapted from ...") and add the entry to the .bib file so that
%      \cite{bibkey} works. Leave the credit out for original figures.
%
%  ASSUMED MACRO DEFINITIONS  (compare with your preamble; do not
%  uncomment if they already exist)
%    \newcommand{\labfig}[1]{\label{fig:#1}}
%    \newcommand{\reffig}[1]{Figure~\ref{fig:#1}}
%    \newcommand{\labtab}[1]{\label{tab:#1}}
%    \newcommand{\reftab}[1]{Table~\ref{tab:#1}}
%
%  PACKAGES THESE TEMPLATES USE
%    graphicx, tikz, booktabs, array, ragged2e,
%    longtable (only for template 7)
%
% =====================================================================

\section{Text, lists, and margin notes}
\labsec{cookbook-text}
Use \texttt{\string\section[short title]\{full title\}} when a long heading needs a shorter table-of-contents entry. Place project labels immediately after the item being labeled, such as \texttt{\string\labsec\{unique-key\}} after a section heading.

\subsection{Lists}
\begin{itemize}
  \item Use an unordered list for related concepts.
  \item Nest items when the hierarchy is meaningful.
  \begin{itemize}
    \item Nested bullets use the project’s smaller bullet style.
  \end{itemize}
\end{itemize}
\begin{enumerate}
  \item Use numbered steps when order matters.
  \item Continue with the next action or consequence.
\end{enumerate}
\begin{description}
  \item[Term] Explain a defined term or a short item-label pair.
  \item[Second term] Keep descriptions concise and parallel.
\end{description}

An ordinary margin note can be placed with \texttt{\string\marginnote[.4cm]\{Brief note.\}}. A numbered sidenote uses \texttt{\string\sidenote\{Brief note.\}}; for example, \sidenote{A short note in the outer margin.} Use margin notes sparingly; longer explanations belong in the main text or a box.

\subsection{Project typography helpers}
The preamble defines small typography helpers: \invitro experiments, \invivo observations, \cis and \trans configurations, \etal citations, \denovo mutations, \adhoc choices, \eg examples, \ie clarifications, and \etcetera. Commands such as \Command{section}, \Package{booktabs}, and \Path{assets/} print technical names consistently.

\section{Equations, definitions, and theorems}
\labsec{cookbook-math}
For a numbered equation, add a project label inside the equation environment:
\begin{equation}
  C = \frac{n}{V}
  \labeq{concentration-example}
\end{equation}
The relationship is shown in \refeq{concentration-example}. A wide equation can use the \texttt{wideequation} wrapper:
\begin{wideequation}
  \Delta G = \Delta G^{\circ} + RT\ln Q
\end{wideequation}
\begin{definition}
  Concentration is the amount of a substance per unit volume.
  \labdef{concentration-example}
\end{definition}
\begin{theorem}
  In this example, doubling amount while holding volume fixed doubles concentration.
  \labthm{concentration-example}
\end{theorem}
\begin{remark}
  Available theorem-like environments include theorem, proposition, lemma, corollary, definition, remark, example, and exercise.
\end{remark}

\section{Code, citations, and references}
\labsec{cookbook-references}
Use \texttt{lstlisting} for short code samples:
\begin{lstlisting}[language=Python,caption={A short code listing.},label={lst:example}]
concentration = amount / volume
print(concentration)
\end{lstlisting}
The bibliography is stored in \texttt{main.bib} and processed with Biber. Standard examples are \texttt{\string\textcite\{Costanzo2014BRS\}} and \texttt{\string\parencite\{Costanzo2014BRS\}}; in prose, \textcite{Costanzo2014BRS} discusses physiology, while a parenthetical citation can be written \parencite[chap.~1]{Costanzo2014BRS}. The custom \texttt{\string\sidecite} also places a formatted citation in the margin: \sidecite{Costanzo2014BRS}.

Project reference helpers use matching label and reference prefixes: \texttt{\string\labsec\{key\}} with \texttt{\string\refsec\{key\}}, \texttt{\string\labfig\{key\}} with \texttt{\string\reffig\{key\}}, and \texttt{\string\labtab\{key\}} with \texttt{\string\reftab\{key\}}. For example, see \refsec{cookbook-boxes}, \reftab{example_planning_table}, and \reffig{tikz-flow}. Chapter, subsection, equation, definition, theorem, proposition, lemma, remark, example, and exercise labels have corresponding helpers; see \texttt{template/kaorefs.sty} for the complete command list.

\section{TikZ shapes and colors}
\labsec{cookbook-tikz}
TikZ is loaded by the project template. Define nodes with shape, fill, and line options, then connect them with paths:
\begin{center}
\begin{tikzpicture}[>=stealth]
  \node[draw,circle,fill=ForestGreen!20,minimum size=1.2cm] (one) at (0,0) {1};
  \node[draw,rounded corners,fill=RoyalBlue!15,minimum width=2.2cm,minimum height=1cm] (two) at (3,0) {Process};
  \draw[->,very thick,Goldenrod] (one) -- (two);
\end{tikzpicture}
\end{center}
Available colors include names from \texttt{xcolor} with the \texttt{dvipsnames} option; mix a color with white, such as \texttt{RoyalBlue!15!White}, for a pale fill. Reusable TikZ styles can be declared locally in picture options or globally in the preamble.
